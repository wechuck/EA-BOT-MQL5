# 🚀 Quick Start Guide - Trading Assistant EA

## Get Started in 5 Minutes!

### Step 1: Installation ⚙️
```
1. Copy the entire TradingAssistant folder
2. Paste into: MT5 Data Folder → MQL5 → Experts
3. Open MetaEditor (F4)
4. Navigate to TradingAssistant_EA.mq5
5. Click Compile (F7)
6. Check for "0 errors" message
```

### Step 2: Setup 📊
```
1. Open MT5
2. Open XAUUSD chart
3. Set timeframe to H1 or H4
4. Drag TradingAssistant_EA onto chart
5. Click "Enable AutoTrading" button (top toolbar)
6. Configure settings (or use defaults)
7. Click OK
```

### Step 3: Configure Alerts 📱
```
In MT5:
1. Tools → Options → Notifications
2. Check "Enable Push Notifications"
3. Get MetaQuotes ID from mobile app
4. Enter MetaQuotes ID
5. Click "Test" to verify

In MT5 Mobile App:
1. Settings → Messages → Enable
2. Allow notifications in phone settings
```

### Step 4: Verify Dashboard ✅
```
You should see:
✓ Dark dashboard panel on left side of chart
✓ "TRADING ASSISTANT" header
✓ 5 information panels
✓ Signal status showing "WATCHING"
✓ Execution quality showing current spread
```

### Step 5: Wait for Signal 🎯
```
When a high-quality setup is detected:
1. You'll receive push notification on phone
2. Dashboard shows "ACTIVE" signal
3. Signal strength bar shows quality %
4. Recommended lot size displayed
```

### Step 6: Manual Entry 👨‍💻
```
1. Review the chart yourself
2. Check signal type (buy/sell)
3. Verify recommended lot size
4. Check spread is good (green indicator)
5. If you agree: Open trade MANUALLY
6. If you disagree: Ignore signal
```

### Step 7: EA Takes Over 🤖
```
After you open position:
1. EA detects your trade
2. Automatically sets Stop Loss
3. Automatically sets Take Profit
4. Begins trailing stop monitoring
5. Dashboard updates with trade info
6. You can relax - EA manages it!
```

## 🆘 Troubleshooting

### "Dashboard not showing"
→ Right-click chart → Properties → Show Objects

### "No signals after 3 days"
→ Normal! System is selective. Average 1 signal per 1-2 days

### "EA not managing my trade"
→ Check EA is still running (smiley face in corner)
→ Check trade is on same symbol as EA chart

### "Spread always red"
→ Check actual spread in Market Watch
→ May need to adjust MaxSpread setting
→ Or wait for better market conditions
